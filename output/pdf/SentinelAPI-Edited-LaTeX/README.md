# SentinelAPI project report

This folder contains the editable source for the 40-page A4 IT305 Information Security report. `main.tex` is the root document; it includes graphics from `assets/` and TypeScript excerpts from `code/`.

- **Overleaf:** Upload the ZIP as a new project, choose **XeLaTeX** under the compiler settings, and recompile `main.tex`.
- **Local TeX:** Run `latexmk -xelatex main.tex` from this folder. Alternatively, run `tectonic main.tex`.

The institute masthead and campus strip come from the supplied reference PDF. The seal is the supplied institute logo. The Defense Lab figure is a screenshot of the project running locally. The code snippets are short excerpts from the SentinelAPI repository, with indentation normalized for the listings.
